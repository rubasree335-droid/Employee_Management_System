# 👥 Employee Management System

A desktop application to manage employee records, attendance and departments, built with Python, Tkinter and MySQL.

## ✨ Features

- Manage employee records (add, view, update, delete)
- **Attendance tracking module** to record and view employee attendance
- **Department management module** to organise employees by department
- MySQL database for storing data
- Simple, user-friendly Tkinter interface

## 🛠️ Tech Stack

- Python
- Tkinter (GUI)
- MySQL

## 🚀 How to Run

1. Clone the repository
   git clone https://github.com/rubasree335-droid/Employee_Management_System.git
2. Install the MySQL connector
   pip install mysql-connector-python
3. Open MySQL and run the `database.sql` file to create the tables
4. Open the code file and enter your own MySQL username and password in the connection line
5. Run the app
    [python gui.py]
